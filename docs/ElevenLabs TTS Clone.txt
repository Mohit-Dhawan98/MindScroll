## Document 1: WebSocket Server Implementation

### Overview
The WebSocket server forms the core communication layer, handling bidirectional streaming between clients and the TTS system. Built on FastAPI for performance and async support, it implements a producer-consumer pattern for concurrent text processing and audio streaming.

### Architecture Details

#### Connection Lifecycle Management
The WebSocket server maintains connection state throughout the session lifecycle:

**Connection States:**
- `CONNECTING`: Initial handshake
- `ACTIVE`: Ready for bidirectional communication
- `PROCESSING`: Currently synthesizing audio
- `DRAINING`: Flushing remaining buffers
- `CLOSING`: Graceful shutdown initiated

**State Transitions:**
```
CONNECTING → ACTIVE → PROCESSING ↔ ACTIVE → DRAINING → CLOSING
                          ↑_______________|
```

#### Message Protocol Implementation

**Input Message Handling:**
The server processes four distinct message types:

1. **Initialization Message**
   - Text: Single space `" "`
   - Flush: `false`
   - Action: Initialize session state, warm up model
   - No audio generation triggered

2. **Text Accumulation Message**
   - Text: Any string content
   - Flush: `false`
   - Action: Append to buffer, check threshold
   - Generation triggered if buffer exceeds optimal chunk size

3. **Force Generation Message**
   - Text: Any content (including empty)
   - Flush: `true`
   - Action: Immediately process all buffered text
   - Maintains connection after generation

4. **Termination Message**
   - Text: Empty string `""`
   - Flush: `false`
   - Action: Generate remaining buffer, close connection
   - Send final chunk with `is_final: true`

**Text Buffer Architecture:**

#### Producer-Consumer Pattern

**Producer Task (Text → Audio):**
```python
async def producer_task():
    while active:
        text = await text_queue.get()
        if should_generate(text):
            audio_chunks = await synthesize(text)
            for chunk in audio_chunks:
                await audio_queue.put(chunk)
```

**Consumer Task (Audio → Client):**
```python
async def consumer_task():
    while active:
        audio_chunk = await audio_queue.get()
        message = format_output(audio_chunk)
        await websocket.send_json(message)
```

#### Error Handling and Recovery

**Connection Error Handling:**
- Automatic reconnection with exponential backoff
- State preservation across reconnections
- Graceful degradation on model failures
- Circuit breaker pattern for system protection

**Error Types and Responses:**
| Error Type | Response Strategy | Client Notification |
|------------|------------------|---------------------|
| Model failure | Fallback to backup model | Error message with retry |
| Memory overflow | Clear caches, continue | Warning with degraded quality |
| Network timeout | Buffer and retry | Temporary pause indication |
| Invalid input | Skip and continue | Error with specific issue |

- Hidden state size: 1024 dimensions
- Vocabulary: 8,000 tokens
- Native sampling rate: 24,000 Hz

2. Encoder processes tokens incrementally
3. Decoder maintains attention state

## Document 3: Character Alignment System

### Overview
The alignment system provides character-level timing information for synthesized speech, essential for applications requiring precise audio-text synchronization.

### Alignment Extraction Methods

#### Method 1: Native Alignment (Kyutai)

**Word-Level Extraction:**
```python
def extract_kyutai_alignments(model_output):
    # Kyutai provides word boundaries natively
    word_boundaries = model_output.word_timings
    # Each boundary contains: (word, start_ms, end_ms)
```

**Character Interpolation Algorithm:**
```python
def interpolate_to_characters(word_boundaries, text):
    char_timings = []
    for word, start_ms, end_ms in word_boundaries:
        word_duration = end_ms - start_ms
        char_count = len(word)
        
        # Weighted distribution based on character type
        weights = calculate_character_weights(word)
        
        # Distribute time proportionally
        cumulative = start_ms
        for char, weight in zip(word, weights):
            char_duration = (word_duration * weight) / sum(weights)
            char_timings.append({
                'char': char,
                'start': cumulative,
                'duration': char_duration
            })
            cumulative += char_duration
```

**Character Weight Calculation:**
- Vowels: 1.2x weight (longer duration)
- Consonants: 1.0x weight (standard)
- Punctuation: 0.5x weight (brief)
- Spaces: 0.3x weight (minimal)

#### Method 2: Attention-Based (XTTS-v2)

**Attention Matrix Extraction:**
```python
def extract_attention_alignments(model, text, mel_spectrogram):
```

**Monotonic Path Finding:**
```python
def find_monotonic_path(attention_matrix):
    # Dynamic programming approach
    path = []
    prev_frame = 0
    
    for text_idx in range(len(attention_matrix)):
        # Find peak attention for this text position
        attention_slice = attention_matrix[text_idx, prev_frame:]
        peak_frame = prev_frame + np.argmax(attention_slice)
        
        path.append((text_idx, peak_frame))
        prev_frame = peak_frame
```

**Frame to Time Conversion:**
- Hop length: 256 samples
- Sample rate: 22,050 Hz
- Frame duration: 256/22050 = 11.6ms
- Time = frame_index * 11.6ms

#### Method 3: Token-Based (Orpheus)

**Token Boundary Mapping:**
```python
def extract_token_alignments(token_sequence, text):
    # Each token represents ~20ms of audio
    token_duration = 20  # milliseconds
    
    # Map tokens back to characters
    char_to_token = map_characters_to_tokens(text, token_sequence)
    
    alignments = []
    for char_idx, token_indices in char_to_token.items():
        start_time = min(token_indices) * token_duration
        end_time = (max(token_indices) + 1) * token_duration
        alignments.append({
            'char': text[char_idx],
            'start': start_time,
            'duration': end_time - start_time
        })
```

**Token-Character Mapping:**
- Subword tokens may span multiple characters
- Characters may span multiple tokens
- Maintain many-to-many mapping
- Resolve conflicts with heuristics

### Alignment Post-Processing

#### Smoothing and Refinement

**Boundary Smoothing:**
```python
def smooth_alignments(alignments, window_size=3):
    smoothed = []
    for i, alignment in enumerate(alignments):
        # Average with neighbors
        start_times = []
        durations = []
        
        for j in range(max(0, i-window_size), 
                      min(len(alignments), i+window_size+1)):
            start_times.append(alignments[j]['start'])
            durations.append(alignments[j]['duration'])
        
        smoothed.append({
            'char': alignment['char'],
            'start': np.median(start_times),
            'duration': np.median(durations)
        })
```

**Constraint Enforcement:**
- Monotonicity: Ensure start times increase
- Continuity: No gaps between characters
- Minimum duration: At least 10ms per character
- Maximum duration: Cap at 500ms per character

#### Quality Metrics

**Alignment Accuracy Metrics:**
```python
def calculate_alignment_metrics(predicted, ground_truth):
    metrics = {
        'boundary_error': [],  # ms difference at boundaries
        'duration_error': [],  # duration prediction error
        'overlap_ratio': []    # overlap with ground truth
    }
    
    for pred, true in zip(predicted, ground_truth):
        boundary_error = abs(pred['start'] - true['start'])
        duration_error = abs(pred['duration'] - true['duration'])
        overlap = calculate_overlap(pred, true)
        
        metrics['boundary_error'].append(boundary_error)
        metrics['duration_error'].append(duration_error)
        metrics['overlap_ratio'].append(overlap)
```

**Target Performance:**
- Boundary accuracy: ±50ms
- Duration accuracy: ±30ms
- Overlap ratio: >80%

### Crossfade Implementation

#### Crossfade Mathematics
```python
def crossfade(audio1, audio2, overlap_samples):
    # Linear crossfade
    fade_out = np.linspace(1.0, 0.0, overlap_samples)
    fade_in = np.linspace(0.0, 1.0, overlap_samples)
    
    # Apply fades
    audio1_fade = audio1[-overlap_samples:] * fade_out
    audio2_fade = audio2[:overlap_samples] * fade_in
    
    # Combine
    crossfaded = audio1_fade + audio2_fade
    
    # Concatenate
    result = np.concatenate([
        audio1[:-overlap_samples],
        crossfaded,
        audio2[overlap_samples:]
    ])
    
    return result
```

**Cosine Crossfade (Smoother):**
```python
def cosine_crossfade(audio1, audio2, overlap_samples):
    t = np.linspace(0, np.pi, overlap_samples)
    fade_out = 0.5 * (1 + np.cos(t))
    fade_in = 0.5 * (1 - np.cos(t))
```

```python
def equal_power_crossfade(audio1, audio2, overlap_samples):

    fade_in = np.sin(t)
```

```python
def apply_antialiasing(audio, source_sr, target_sr):
    # Nyquist frequency
    nyquist = min(source_sr, target_sr) / 2
    
    # Design lowpass filter
    sos = signal.butter(
        8,  # Order
        nyquist * 0.95,  # Cutoff
        btype='low',
        fs=source_sr,
        output='sos'
    )
    
    # Apply filter
    filtered = signal.sosfilt(sos, audio)
    
    return filtered
```

#### Float32 to Int16 PCM

```python
def float_to_pcm16(audio_float32):
    # Ensure range [-1, 1]
    audio_clipped = np.clip(audio_float32, -1.0, 1.0)
    
    # Scale to int16 range
    audio_int16 = (audio_clipped * 32767).astype(np.int16)
    
    return audio_int16
```

#### PCM Encoding
```python
def encode_pcm_wave(audio_int16, sample_rate=44100):
    # Create WAV header
    byte_rate = sample_rate * 2  # 16-bit mono
    block_align = 2
    
    wav_header = struct.pack(
        '<4sI4s4sIHHIIHH4sI',
        b'RIFF',
        36 + len(audio_int16) * 2,
        b'WAVE',
        b'fmt ',
        16,  # PCM
        1,   # Audio format (PCM)
        1,   # Channels (mono)
        sample_rate,
        byte_rate,
        block_align,
        16,  # Bits per sample
        b'data',
        len(audio_int16) * 2
    )
    
    # Combine header and data
    wav_bytes = wav_header + audio_int16.tobytes()
    
    return wav_bytes
```

### Audio Quality Enhancement

#### Noise Reduction
```python
def reduce_noise(audio, sample_rate):
    # Spectral subtraction
    D = librosa.stft(audio)
    magnitude = np.abs(D)
    phase = np.angle(D)
    
    # Estimate noise floor (first 100ms)
    noise_frames = int(0.1 * sample_rate / 512)
    noise_profile = np.mean(magnitude[:, :noise_frames], axis=1)
    
    # Subtract noise
    magnitude_clean = magnitude - noise_profile[:, np.newaxis]
    magnitude_clean = np.maximum(magnitude_clean, 0)
    
    # Reconstruct
    D_clean = magnitude_clean * np.exp(1j * phase)
    audio_clean = librosa.istft(D_clean)
    
    return audio_clean
```

#### Dynamic Range Compression
```python
def compress_dynamic_range(audio, threshold=-20, ratio=4):
    # Convert to dB
    audio_db = 20 * np.log10(np.abs(audio) + 1e-10)
    
    # Apply compression
    over_threshold = audio_db > threshold
    audio_db[over_threshold] = threshold + (audio_db[over_threshold] - threshold) / ratio
    
    # Convert back to linear
    audio_compressed = np.sign(audio) * (10 ** (audio_db / 20))
    
    return audio_compressed
```

#### Loudness Normalization
```python
def normalize_loudness(audio, target_lufs=-16):
    # Measure current loudness
    current_lufs = measure_integrated_loudness(audio)
    
    # Calculate gain
    gain_db = target_lufs - current_lufs
    gain_linear = 10 ** (gain_db / 20)
    
    # Apply gain with limiting
    audio_normalized = audio * gain_linear
    audio_normalized = np.clip(audio_normalized, -1.0, 1.0)
    
    return audio_normalized
```

#### Chunk Size Optimization
```python
def determine_optimal_chunk_size(latency_target, sample_rate):
    # Balance latency vs efficiency
    if latency_target < 100:  # Ultra-low latency
        chunk_ms = 20
    elif latency_target < 200:  # Low latency
        chunk_ms = 50
    else:  # Standard
        chunk_ms = 100
    
    chunk_samples = int(chunk_ms * sample_rate / 1000)
    
    # Align to power of 2 for FFT efficiency
    chunk_samples = 2 ** int(np.log2(chunk_samples))
    
    return chunk_samples
```

```python
class StreamingAudioBuffer:
    def __init__(self, size=32768):
        self.buffer = collections.deque(maxlen=size)
        self.lock = threading.Lock()
        
    def add_audio(self, audio):
        with self.lock:
            self.buffer.extend(audio)
            
    def get_chunk(self, size):
        with self.lock:
            if len(self.buffer) >= size:
                chunk = [self.buffer.popleft() for _ in range(size)]
                return np.array(chunk)
            return None
```

```python
class MemoryManager:
    def __init__(self, reserved_gb=2):
        self.reserved = reserved_gb * 1024**3
        self.total = torch.cuda.get_device_properties(0).total_memory
        self.available = self.total - self.reserved
        
    def allocate_for_model(self, model_name):
        allocations = {
            'kyutai': 8 * 1024**3,
            'xtts': 6 * 1024**3,
            'orpheus': 4 * 1024**3,
            'chatterbox': 4 * 1024**3,
            'kokoro': 350 * 1024**2,
        }
        
        required = allocations.get(model_name, 4 * 1024**3)
        
        if required > self.available:
            self.clear_cache()
            
        return required
        
    def clear_cache(self):
        import gc
        gc.collect()
        torch.cuda.empty_cache()
        torch.cuda.synchronize()
```

```python
class ConnectionManager:
    def __init__(self, max_connections=10):
        self.active_connections = {}
        self.max_connections = max_connections
        self.connection_semaphore = asyncio.Semaphore(max_connections)
        
    async def accept_connection(self, websocket, connection_id):
        async with self.connection_semaphore:
            if len(self.active_connections) >= self.max_connections:
                await websocket.close(code=1008, reason="Server at capacity")
                return False
                
            self.active_connections[connection_id] = {
                'websocket': websocket,
                'created_at': time.time(),
                'last_activity': time.time(),
                'state': 'active',
            }
            
            return True
            
    async def remove_connection(self, connection_id):
        if connection_id in self.active_connections:
            del self.active_connections[connection_id]
```

### Error Recovery

#### Circuit Breaker Pattern
```python
class CircuitBreaker:
    def __init__(self, failure_threshold=5, recovery_timeout=60):
        self.failure_threshold = failure_threshold
        self.recovery_timeout = recovery_timeout
        self.failure_count = 0
        self.last_failure_time = None
        self.state = 'closed'  # closed, open, half_open
        
    async def call(self, func, *args, **kwargs):
        if self.state == 'open':
            if time.time() - self.last_failure_time > self.recovery_timeout:
                self.state = 'half_open'
                self.failure_count = 0
            else:
                raise Exception("Circuit breaker is open")
                
        try:
            result = await func(*args, **kwargs)
            
            if self.state == 'half_open':
                self.state = 'closed'
                self.failure_count = 0
                
            return result
            
        except Exception as e:
            self.failure_count += 1
            self.last_failure_time = time.time()
            
            if self.failure_count >= self.failure_threshold:
                self.state = 'open'
                logging.error(f"Circuit breaker opened: {str(e)}")
                
            raise e
```

```python
class GracefulDegradation:
    def __init__(self):
        self.degradation_levels = {
            'normal': {'quality': 'high', 'latency': 'low'},
            'degraded': {'quality': 'medium', 'latency': 'medium'},
            'minimal': {'quality': 'low', 'latency': 'high'},
        }
        self.current_level = 'normal'
        
    def assess_system_state(self, metrics):
        gpu_util = metrics.get('gpu_utilization_avg', 0)
        memory_free = metrics.get('memory_free_mb', 1000)
        error_rate = metrics.get('error_rate', 0)
        
        if gpu_util > 90 or memory_free < 500 or error_rate > 0.1:
            self.current_level = 'minimal'
        elif gpu_util > 70 or memory_free < 1000 or error_rate > 0.05:
            self.current_level = 'degraded'
        else:
            self.current_level = 'normal'
            
        return self.current_level
        
    def get_settings(self):
        if self.current_level == 'minimal':
            return {
                'model': 'kokoro',  # Fastest model
                'quantization': 'int8',
                'chunk_size': 50,
                'cache_only': True,
            }
        elif self.current_level == 'degraded':
            return {
                'model': Config.MODEL_SELECTION,
                'quantization': 'int8',

            }

                'model': Config.MODEL_SELECTION,
```
